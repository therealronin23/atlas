# CAPABILITIES — compatibilidad histórica

Este fichero ya no es una autoridad de estado. Su tabla anterior mezclaba
código, wiring, configuración, observaciones históricas y producción real;
también conservaba como “construidos” módulos que ya no existen en el árbol.
Mantener otra lista mutable duplicaría precisamente el problema que compila la
candidata definitiva.

- estado humano y preflight: [`STATUS.md`](../../STATUS.md);
- estado machine-readable por componente/capacidad:

- precedencia y vocabulario: [`docs/canon/authority_registry.yaml`](../canon/authority_registry.yaml).

ningún claim `CODE_PRESENT`, `TESTED`, `WIRED`, `RUNTIME_CONFIGURED`,
`LIVE_VERIFIED` o `PRODUCT_ACCEPTED` se deriva de este redirect.
